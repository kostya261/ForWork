# ForWork ERP

ERP-система для управления задачами, складом, инвентарём, документами и финансами.

## Возможности

### Управление задачами
- Создание, редактирование, удаление задач
- Назначение ответственных и соисполнителей
- Статусы и приоритеты
- Требуемые материалы и инвентарь
- Комментарии и история изменений
- Наряды на работу и акты выполненных работ

### Складской учёт
- Приходные и расходные накладные
- Перемещение товаров между складами
- Инвентаризация
- Стеллажи и ячейки хранения
- Отчёты: остатки по складам, оборотная ведомость
- Печатные формы (PDF)

### Учёт основных средств (инвентаря)
- Ввод в эксплуатацию, списание, перемещение
- Инвентаризация ОС
- Закрепление за ответственными

### Финансы
- Счета на оплату
- Счета-фактуры
- Печатные формы

### Коммуникации
- Внутренний чат (общий и личный)
- Уведомления (колокольчик)
- Email-уведомления

### Справочники
- Контрагенты
- Сотрудники (с паспортными данными, транспортом)
- Отделы (иерархия)
- Производители
- Категории склада и инвентаря

## Технологический стек

- **Backend:** Python 3.13, Django 5.x, Django REST Framework
- **Database:** PostgreSQL
- **Frontend:** Bootstrap 5, JavaScript (Vanilla), Select2
- **API:** REST API, JWT-аутентификация, Swagger-документация
- **PDF:** WeasyPrint
- **Зависимости:** см. `pyproject.toml`

## Установка и запуск

### 1. Клонировать репозиторий
```
  bash
  git clone https://github.com/kostya261/ForWork.git
  cd ForWork
```
### 2. Установить зависимости
    poetry install

### 3. Настроить переменные окружения

Создать файл .env в корне проекта:
SECRET_KEY=your-secret-key
DEBUG=True
DB_NAME=forwork_db
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432

### 4. Создать базу данных PostgreSQL

CREATE DATABASE forwork_db;

### 5. Применить миграции

python manage.py migrate

### 6. Создать суперпользователя

python manage.py createsuperuser

### 7. Запустить сервер

python manage.py runserver


Открыть http://127.0.0.1:8000/

Документация API
После запуска сервера документация доступна по адресам:

Swagger UI: http://127.0.0.1:8000/swagger/

ReDoc: http://127.0.0.1:8000/redoc/
